Privacy Policy

FRONTIER Drive Sync · Effective October 25, 2026

1. Who operates the application

FRONTIER Drive Sync is an independent, personal-use utility operated by PLATA87. It is not a public multi-user service. For privacy questions, contact the project owner through the PLATA87 GitHub profile or the support contact shown in the Google OAuth consent screen.

2. Purpose of Google access

With the owner's explicit authorization, the application uses the Google Drive API to create, read, update and organize selected research output files in the owner's Google Drive. It maintains latest files and historical snapshots. The Google OAuth scope is https://www.googleapis.com/auth/drive.file.

3. What information is processed

The app processes only the files selected for synchronization, relevant Google Drive file metadata (such as names and IDs), content hashes used for change detection, and OAuth credentials necessary for API access. It does not request Google Mail, Google Photos, Google contacts or account-administration scopes.

4. Storage, sharing and retention

The Python utility runs on devices controlled by the owner and sends selected files directly to Google's servers using the Google Drive API. OAuth authentication files are stored locally on the owner's device; this informational website does not receive them. Synced files and historical snapshots are retained in the owner's Google Drive until the owner removes them. Google processes Drive data in accordance with its own terms and privacy policy. No research files or OAuth credentials are intentionally published through this website or sold to advertisers.

5. Website operation

This static website does not provide a sign-in form, upload facility, or deliberately embedded advertising or analytics. It is hosted through GitHub Pages, whose infrastructure may process technical access information according to GitHub's privacy statement.

6. Revoking access and deleting data

The owner can revoke the app's Google access at any time through Google Account → Third-party connections. Revoking access stops further authorized API activity but does not automatically delete files already saved in Google Drive. The owner can separately delete those files in Drive and remove the locally stored authorization file.

7. Changes to this policy

Changes will be published on this page with an updated effective date. The description reflects the current personal-use deployment; any future service offered to other users will require a review of data-handling practices and disclosures.
